# Data Pipeline

This folder contains scraping and indexing utilities for legal sources. All scrapers must respect robots.txt, use polite delays, and support resume-on-failure. Do not scrape any portal that disallows automated access.

## Planned Scrapers
- eCourts services
- NJDG
- India Code (Bare Acts)
- Supreme Court + High Courts
- QA portals (requires explicit permission)

## Execution
Scrapers are placeholders until permissions and API keys are confirmed.
